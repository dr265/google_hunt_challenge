# NEXUS AI — Campus Intelligence Command Center

> **One AI layer across every campus system.** Multi-agent intelligence that sees,
> correlates, decides, and speaks — operated by voice through JARVIS.

---

## The problem

A modern university campus runs on 10+ **independent** systems — academics, transport,
security, hostels, power, network, health centre, facilities. Each has its own dashboard
and its own alerts. Nobody sees the *connections*:

- A delayed bus route + a 09:00 exam slot = 1,240 students arriving late.
- A voltage dip + an auditorium event in the same building = a power failure at peak load.
- Six SLA-breached maintenance complaints in one block = one hidden root cause.

Staff still discover these correlations **after** they become incidents, by phoning
around. Data exists; coordination doesn't. Student-facing information
(programs, admissions, campus facts) is scattered across websites nobody queries in a hurry.

## Our solution

NEXUS AI is a single command layer that sits above siloed campus systems:

1. **Ingests** events from every campus system into one correlated event stream.
2. **Reasons** across domains with a multi-agent orchestrator (Academic, Transport,
   Security, Hostel, Maintenance, Emergency agents).
3. **Decides** with evidence, confidence scores, risks and constraints — never a black box.
4. **Acts** through approval-gated actions (notify, escalate, create maintenance request).
5. **Speaks** — JARVIS, a real tool-calling voice agent, answers any operator question
   out loud and grounds every answer in live data instead of guessing.

## Architecture

```
React 18 + TS + Vite UI  ──►  FastAPI backend  ──►  CleanApis gateway (Gemini flash)
   landing / JARVIS voice /       campus state API        JARVIS agent: LLM + tools
   campus / agents / decisions     AI web scraper         scraper: page → LLM extraction
                                   event stream           auth: Clerk → session token
```

**Tech stack:** React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide,
Clerk (Google OAuth), Python 3.13, FastAPI, Uvicorn, BeautifulSoup4, PyJWT,
OpenAI-compatible LLM gateway.

**Engineering details worth mentioning to judges:**
- The agent loop feeds tool results back in a flattened message format after we
  discovered the gateway 502s on OpenAI-style multi-turn `tool_calls` payloads — the
  fix is documented in code.
- The scraper caches results (6 h TTL) and refreshes in a background thread so the UI
  never blocks on network I/O.
- Every LLM call has model fallback (`gemini-3.7-flash` → `gemini-3.6-flash` → `gemma-2-2b`)
  plus one retry per model for transient 5xx.
- The dashboard never shows an empty/`0` state — fallbacks guarantee data is always present.

## 2-minute demo script

1. **Landing** — premium hero, "Launch NEXUS".
2. **Command Center** — KPI strip: systems online, degraded, workflows, agents; JARVIS
   Voice Console with the human-portrait reel behind it.
3. Tap the mic (or type): *"What is happening across campus right now?"*
   → Watch the live tool chips light up (`campus_status`, `campus_agents`,
   `campus_incidents`, `campus_decisions`) → JARVIS **speaks** the correlated briefing.
4. Ask: *"Where is SRM University AP and how big is the campus?"*
   → JARVIS calls the scraper tool and answers from **live scraped data**
   ("Neerukonda, Mangalagiri, Guntur District… 100-acre campus designed by Perkins & Will").
5. **Decisions** — open an AI decision: evidence, confidence (91%), risks, approval gate.
6. **Incidents** — severity timeline with cross-system correlation.
7. **Get in touch** — typewriter hero, multi-select services, springy acknowledgment banner.

## Why we win

- **Not a chatbot wrapper** — a genuine tool-calling agent that must ground facts in tools
  and refuses to fabricate (a hard rule in its system prompt).
- **Cross-system correlation is the product**, not a single-domain dashboard.
- **Voice-first operator experience** — hands-free in an operations room.
- **Explainable decisions** — evidence, confidence factors, risks, approvals.
- **Real web intelligence** — an LLM-driven scraper that structures a live university site.
- **Runs offline-tolerant** — resilient fallbacks, cached knowledge, one-click start.
